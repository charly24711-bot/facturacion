# Tax Calculator

Esta skill permite calcular con precisión matemática (usando Decimal) el desglose impositivo de un importe según las leyes de Paraguay.

## Uso
Importar la función `calcular_iva_linea` o ejecutar el script directamente para una demostración.

```bash
python .agents/skills/tax_calculator/scripts/tax_calculator.py
```
