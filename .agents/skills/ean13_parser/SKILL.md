# EAN-13 Parser

Esta skill permite parsear los códigos de barras generados por balanzas de mostrador.

## Uso
Importar la función en tu código o ejecutar el script directamente para probar un código.

```bash
python .agents/skills/ean13_parser/scripts/ean13_parser.py 2000105012503
```
